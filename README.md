# My-Skills

Personal Hermes Agent skills collection.

## Skills

- `code-audit` — audit, validate, and autofix code quality / production-readiness issues.
- `prompt-builder` — build and refine prompts for AI agents and autopilot workflows.

## Install

Copy a skill directory into your Hermes skills folder:

```bash
mkdir -p ~/.hermes/skills/software-development
cp -a skills/software-development/code-audit ~/.hermes/skills/software-development/
cp -a skills/software-development/prompt-builder ~/.hermes/skills/software-development/
```

Restart or open a new Hermes session after installing so the skill loader can pick it up.
